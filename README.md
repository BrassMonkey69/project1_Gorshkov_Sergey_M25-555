# project1_Gorshkov_Sergey_M25-555
labyrinth_of_treasures

Запуск игры производится с помощью команды 'make project'
В игре Вам придется путешествовать по различным полузаброшенным комнатам в поисках сокровищ. На пути к цели Вы сможете подбирать и использовать предметы, решать загадки (за их решение будете получать награду). Удачи в поисках сокровищ!

В описании задачи не было ничего про содержимое текущего файла и тем более про asciinema...
